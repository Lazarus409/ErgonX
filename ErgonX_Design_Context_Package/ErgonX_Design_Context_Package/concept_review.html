Governing product rules (from README)
  • Preserve the approved shell: navy structural sidebar, light top bar, role-aware navigation, tenant-aware identity areas.
  • Use the original supplied raster logo assets; no invented substitute logo artwork.
  • Standard Employees land on Self-Service Home; managers, HR, Finance, Directors and admins land on the general workspace.
  • Insights is permission/module scoped; Executive Dashboard is organization-wide for Institution Admin and Director.
  • Never fabricate production KPI/chart data — governed empty states when data is unavailable.
  • Max two uses of the same visualization type per dashboard (hard acceptance criterion).
  • Only draft/unreferenced config records may be hard-deleted; referenced master data is archived; finalized/posted/paid/approved/audit/security records are never hard-deleted.
  • Corrections use linked adjustment, reversal, void, cancellation or replacement records, keeping the original.

Every brief shares the same template (page header + one primary action, shared primitives, desktop/tablet/mobile rules, permission-driven actions, audit on mutations). The only per-concept difference is one backend rule, shown under each group heading below.
